# Pro&Vet — ветклиника, ветаптека и зоосалон

Лендинг по макету из Figma. Чистые HTML, CSS и JavaScript: без сборки, фреймворков и бэкенда.

## Структура

```
index.html            — главная
services.html         — все услуги и полный прайс-лист с поиском
therapy.html          — терапия и приём
vaccination.html      — вакцинация и чипирование
surgery.html          — хирургия
ophthalmology.html    — офтальмология
diagnostics.html      — диагностика и анализы
grooming.html         — зоосалон (груминг)
pharmacy.html         — ветаптека: каталог, фильтр, бронь товаров
css/style.css         — стили и адаптив
js/main.js            — меню, слайдер врачей, онлайн-запись, поиск, аптека
img/                  — фотографии и иконки
```

Каждая страница направления: прайс-лист, шаги приёма, врачи, ссылки на другие направления и кнопка записи. Запись на этой странице сразу открывается с нужной услугой.

## Ветаптека

Товары фильтруются по категориям и ищутся по названию. Кнопка «Отложить» добавляет товар в список с итоговой суммой, а «Забронировать» оформляет бронь на 24 часа с номером заказа. Список и брони хранятся в `localStorage`. Ссылка вида `pharmacy.html#cat-food` сразу открывает нужную категорию.

## Онлайн-запись

Форма записи работает на всех страницах: её разметку вставляет `js/main.js`. Она открывается любой кнопкой «Записаться», стрелкой у врача или по ссылке вида `index.html#booking`.

- Выбор услуги и специалиста. Есть вариант «любой врач»: система сама подберёт свободного.
- Календарь на 45 дней. Точки под датами показывают загрузку дня: много мест, мало мест, нет мест.
- Сетка слотов с 9:00 до 21:00 с шагом 30 минут. Занятые слоты и обеденный перерыв недоступны, прошедшее время скрыто.
- Имитация сервера: задержки ответов, загрузка расписания и проверка, не заняли ли слот, перед подтверждением.
- Пока форма открыта, «другие пациенты» иногда занимают свободное время.
- Записи сохраняются в `localStorage`. Их можно посмотреть и отменить в разделе «Мои записи» и скачать в календарь (`.ics`).

Занятость генерируется детерминированно от даты и врача, поэтому расписание при каждом заходе одинаковое и выглядит как настоящая база.

Услуги, врачи и часы работы задаются в начале `js/main.js` (константы `SERVICES`, `DOCTORS`, `OPEN_HOUR`, `CLOSE_HOUR`).

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
